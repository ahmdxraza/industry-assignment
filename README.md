# 🏭 Industry Website

### Modern & Responsive Industrial Business Website

A clean and responsive industrial website built using **HTML5 and CSS3**.
This project was created as a beginner-friendly web development assignment.

## ✨ Features

* 🏠 Industrial Hero Section
* ⚙️ Service Cards
* 🏗️ Market Sectors
* 📝 Request a Quote Form
* 📊 Animated Statistics
* 🖼️ Project Gallery
* 📞 Contact Section
* ✨ CSS Hover Animations
* 📱 Mobile Responsive Design
